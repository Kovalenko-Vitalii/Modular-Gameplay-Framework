# Modular Gameplay Framework

A scalable, ready-to-use framework for Unity 6 that provides clean architecture and essential gameplay systems for building a wide range of games.

## 0.02.00 Features

Core:
- VContainer DI based architecture
- Integrated AudioKinetic Wwise audio engine
- Scene Loading system
- Input Management system
- Persistence system
- Setting system

Gameplay:
- Advanced Character Controller
- Camera Headbobbing
- Surface Identification System
- Surface driven footsteps

UI:
- Reusable UI Templates
- Flexible Window system
- Button Sounds
